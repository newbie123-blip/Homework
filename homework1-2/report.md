# 作業二：遞迴求解冪集 (Power Set)

## 解題說明

這題是要寫一個遞迴函式，來印出一個集合裡面所有的子集合（也就是 Power Set）。像題目舉例的，如果輸入集合是 (a, b, c)，那印出來就要有空集合 ()、單個元素的 (a)、(b)、(c)，還有兩個元素的 (a,b)、(a,c)、(b,c)，最後是全部都有的 (a,b,c)，總共會有 $2^3 = 8$ 個子集合。

## 解題策略

我的想法是用遞迴去走每一個位置：
1. 對於目前的元素，分成兩種情況：一種是「不拿」，另一種是「拿」。
2. 如果選了要拿，就把這個元素存進陣列裡，然後繼續去處理下一個元素。
3. 當走完最後一個元素時（也就是 index 到底了），就把目前存好的組合印出來。
4. 印完之後再把剛才放進去的元素拿掉（做回溯），這樣才不會影響到後面其他組合。

## 程式實作

以下為主要程式碼：

```cpp
#include <iostream>
#include <vector>

using namespace std;

void powerset(const vector<char>& S, int index, vector<char>& current) {
    if (index == S.size()) {
        cout << "(";
        for (size_t i = 0; i < current.size(); i++) {
            cout << current[i] << (i + 1 < current.size() ? "," : "");
        }
        cout << ") ";
        return;
    }

    powerset(S, index + 1, current);

    current.push_back(S[index]);
    powerset(S, index + 1, current);
    current.pop_back();
}

int main() {
    vector<char> S = {'a', 'b', 'c'};
    vector<char> current;

    cout << "{ ";
    powerset(S, 0, current);
    cout << "}\n";

    return 0;
}
```

## 效能分析

* **時間複雜度**：$O(n \cdot 2^n)$
  因為集合裡有 $n$ 個元素的話，全部會有 $2^n$ 種不同的組合。遞迴走到底要把當前答案印出來時，還要跑一次最多長度為 $n$ 的迴圈，所以時間複雜度是 $O(n \cdot 2^n)$。
* **空間複雜度**：$O(n)$
  主要佔用記憶體的是遞迴呼叫的層數，還有拿來暫存目前組合的 `current` 陣列，深度最多只會到 $n$ 層，所以空間開銷是 $O(n)$。

## 測試與驗證

### 測試案例

| 測試案例 | 輸入參數 $S$ | 預期輸出 | 實際輸出 |
| :--- | :--- | :--- | :--- |
| 測試一 | $S = \{\}$ | `{ () }` | `{ () }` |
| 測試二 | $S = \{a\}$ | `{ () (a) }` | `{ () (a) }` |
| 測試三 | $S = \{a, b\}$ | `{ () (b) (a) (a,b) }` | `{ () (b) (a) (a,b) }` |
| 測試四 | $S = \{a, b, c\}$ | `{ () (c) (b) (b,c) (a) (a,c) (a,b) (a,b,c) }` | `{ () (c) (b) (b,c) (a) (a,c) (a,b) (a,b,c) }` |

### 編譯與執行指令

```bash
$ g++ -std=c++17 -o powerset powerset.cpp
$ ./powerset
{ () (c) (b) (b,c) (a) (a,c) (a,b) (a,b,c) }
```

## 結論

1. 程式有成功利用遞迴把所有子集合都印出來，結果跟預期的完全一樣。
2. 有在遞迴後面加上 `pop_back()` 把元素狀態復原，沒有讓後面的輸出亂掉。
3. 測試了空集合跟不同長度的字串，輸出都是正確的 $2^n$ 個組合。

## 申論及開發報告

### 選擇遞迴的原因

寫這題的時候會選擇用遞迴來實作，主要有以下幾個原因：

1. **邏輯寫起來最順**
   因為處理每個元素時，就是簡單思考「要選」還是「不選」，用遞迴分成兩條路往下走，程式碼短又很符合這種二元選擇的感覺。

2. **不用手動寫複雜的迴圈控制**
   如果用迴圈寫，可能要用到位元運算去湊出所有組合，但用遞迴配上 `vector` 的 `push_back` 與 `pop_back`，整體寫起來乾淨很多。

3. **比較省記憶體**
   只要用同一個傳參進去的 `current` 陣列去記錄當前的狀態就好，不需要一次開很大的記憶體空間把 $2^n$ 種結果全部存起來再一次印出。
